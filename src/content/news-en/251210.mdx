We are now accepting applications from participating groups for **Wakabasai 2026**!

The event will be held on **Friday, April 10 (16:00–20:00)** and **Saturday, April 11 (10:00–17:00)**.  
This year, **both officially recognized and non-recognized student circles are welcome to participate**.

Please note that there are participation requirements for non-recognized circles, so be sure to review the guidelines before applying.  
The application deadline is **Wednesday, December 31** for non-recognized circles, and **Wednesday, January 7** for officially recognized circles.

Please apply using the application guidelines below.

We look forward to receiving applications from many groups!
